# 下班前清空大脑器

> 把散落在微信、备忘录和脑子里的任务放进来，自动拆成清楚的每日待办。

“下班前清空大脑器”是一款无需登录、无需联网的单页任务整理工具。用户可以直接粘贴一整段杂乱任务，页面会按照中文时间词自动拆分并归入“今天先做”“本周安排”或“待安排”，帮助忙碌的实习生和上班族减少反复整理任务的心理负担。

整个应用只有一个 `index.html` 文件，双击即可使用。任务数据仅保存在当前浏览器中，不会上传到任何服务器。

## 产品理念

- **先接住，再整理**：不用提前规范措辞，一整段粘贴进来即可。
- **符合自然表达**：后续任务会继承最近出现的时间词，更贴近日常说话方式。
- **让优先级一眼可见**：今天、整周和待安排分区展示，重要任务单独标记。
- **轻量且安心**：没有账号、广告、外部接口和数据收集，打开文件就能使用。
- **温柔但不幼稚**：以克制的暖粉、留白、圆角卡片和轻量兔子元素营造治愈感。

## 功能亮点

### 1. 一段文字自动拆成多条任务

支持使用以下符号分隔任务：

- 中文逗号 `，`
- 英文逗号 `,`
- 句号 `。`
- 中文或英文分号 `；` `;`
- 顿号 `、`
- 换行

系统会自动去掉首尾空格，并忽略空白内容。

### 2. 时间上下文自动继承

当某个片段出现明确时间词时，后面紧跟且没有新时间词的任务会沿用同一安排；遇到新的时间词后，再切换到新的日期。

例如：

```text
今天需要秋招 vibe coding、修改网站、上线网站、投简历
```

以上内容会生成 4 条任务，并全部进入“今天先做”，不需要给每一条都重复写“今天”。

再例如：

```text
明天改简历，投产品岗，周五准备笔试，复盘面经
```

分类结果为：

- “明天改简历”和“投产品岗”进入明天对应的星期；
- “周五准备笔试”和“复盘面经”进入周五。

如果任务本身没有时间词，前面也没有可继承的时间信息，则进入“待安排”。

### 3. 支持单日和多日表达

| 输入中的时间词 | 分类结果 |
| --- | --- |
| 今天、今日、今晚、今早、现在、马上、立即、立刻 | 今天先做 |
| 明天、明早、明晚 | 明天对应的星期 |
| 后天 | 后天对应的星期 |
| 周一 / 周二 / … / 周日（也支持“星期”和“礼拜”写法） | 对应星期 |
| 周末 | 周六和周日各生成一条 |
| 工作日 | 周一至周五各生成一条 |
| 每天、每日、天天 | 周一至周日各生成一条 |
| 无明确时间词且无可继承上下文 | 待安排 |

日期会按照**北京时间**计算。本周视图会自动显示当前自然周周一至周日的具体日期，并在日期变化后自动更新。

### 4. 重要任务自动标记

任务中包含以下关键词时，会显示“重要”标签：

```text
必须、截止、紧急、马上
```

例如，“马上提交紧急材料”会进入“今天先做”，并显示“重要”标签。

### 5. 完整的待办操作

- 勾选任务并清晰显示完成状态；
- 单独删除不再需要的任务；
- 一键清空所有已完成任务；
- 没有已完成任务时，“清空已完成”按钮会自动禁用；
- 实时显示全部任务数、已完成数、完成率和进度条。

### 6. 自动本地保存

任务内容、日期分类和完成状态会自动保存在浏览器的 `localStorage` 中。正常情况下，关闭页面或刷新后再次打开，数据仍然保留。

读写本地存储均有异常保护。如果浏览器限制本地文件存储，页面仍可继续使用，并会提示改用 Chrome 或 Edge 重试；此时刷新或关闭页面后，当前状态可能无法保留。

## 快速开始

这个项目不需要安装软件、运行命令或启动服务器。

1. 找到项目文件夹中的 `index.html`。
2. 双击 `index.html`，浏览器会直接打开应用。
3. 在顶部输入框粘贴任务。
4. 点击“帮我拆成每日待办”。
5. 也可以按 `Ctrl + Enter`（Windows）或 `Command + Enter`（macOS）快速添加。

如果双击后没有在浏览器中打开，可以右键点击 `index.html`，选择“打开方式”，再选择 Chrome 或 Edge。

## 页面结构

页面按任务处理顺序分为四个区域：

1. **把任务先放下来**：输入和拆分原始任务；
2. **今天先做**：集中展示今天和需要马上处理的任务；
3. **本周安排**：按北京时间展示本周周一至周日；
4. **待安排**：暂时没有明确日期的任务。

顶部概览区会同步展示任务总数、已完成数量和完成率。

## 技术说明

- 纯 HTML、CSS 和原生 JavaScript；
- 所有页面、样式和逻辑都在 `index.html` 中；
- 不使用框架、第三方库、外部字体、外部图片或 CDN；
- 不调用 API，不依赖大模型或任何外部服务；
- 使用关键词和上下文继承规则进行分类；
- 使用浏览器 `localStorage` 保存任务；
- 根据 UTC+8 计算北京时间和本周日期；
- 支持电脑端与移动端响应式显示。

## 数据与隐私

- 不要求注册或登录；
- 不收集姓名、联系方式或其他个人信息；
- 不会将任务上传到网络；
- 数据只保存在打开此文件的当前浏览器中；
- 清除浏览器站点数据、使用无痕模式或更换浏览器后，原有任务可能无法找回。

如果任务内容比较重要，建议在清理浏览器数据前自行保留一份文字备份。

## 浏览器建议

推荐使用较新版本的 Chrome 或 Edge 直接打开 `index.html`。其他现代浏览器通常也能运行，但不同浏览器对本地文件的存储策略可能不同。
